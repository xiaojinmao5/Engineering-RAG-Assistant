# 🏗️ 工程规范与流程智能问答助手 (RAG-based Engineering Assistant)

## 📖 项目背景
在工程管理领域，施工规范条文分散、流程手续繁杂，传统的全文检索效率低下。本项目基于大语言模型（LLM）与检索增强生成（RAG）技术，构建了一个垂直领域的智能问答助手。用户可通过自然语言提问，系统从本地知识库中检索相关规范条文，生成**带有明确来源引用**的准确回答，有效减少大模型幻觉。

## 🛠️ 技术栈
- **开发语言**：Python 3
- **大模型**：DeepSeek API (deepseek-chat)
- **前端框架**：Streamlit
- **核心逻辑**：基于正则表达式与关键词匹配的轻量级检索链路

## ✨ 核心亮点与工程化设计
1. **按条款切分策略**：针对工程规范“第X条”的语义结构，使用正则表达式 `(?=第[一二三四五六七八九十百\d]+条)` 进行精准切分，避免固定长度切分导致的条文截断与主语丢失。
2. **引用溯源机制**：采用 Prompt 工程约束模型必须基于参考规范回答，并在前端利用 Streamlit 的 Expander 组件展示引用原文，增强回答的可信度。
3. **完整RAG闭环**：独立完成了“文档解析 -> 文本切分 -> 相似度检索 -> 上下文拼接 -> 模型生成 -> 前端展示”的全链路闭环。
