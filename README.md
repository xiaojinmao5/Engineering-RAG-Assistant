🏗️ 工程规范与流程智能问答助手 (Engineering-RAG-Assistant)

## 📖 项目背景
施工规范条文分散、流程手续繁杂，传统的全文检索效率低下；而直接将几百页的规范扔给通用大模型，又会因为长文本截断和“AI幻觉”，导致给出的引用条文根本不存在，这对严谨的工程领域是致命的。

本项目从工程管理的实际业务逻辑出发，摒弃了传统的“固定字数切分”模式，创新性地提出了基于正则表达式的“条款级”切分方案，结合 DeepSeek API 强大的推理能力与 Streamlit 的轻量级前端，实现了一个**“找得准、答得快、可追溯”**的 RAG 问答系统。

## ✨ 核心亮点
*   ⚡ **创新性的正则切分 (Regex Chunking)**：放弃传统的固定长度切分，使用正则表达式 `(?=第[一二三四五六七八九十百\d]+条)`，精准按“第X条”将规范切片，保证每一条工程规范语义的绝对完整（0截断）。
*   🎯 **零幻觉的“引用溯源” (Citation Tracing)**：前端 UI 利用 Streamlit 的折叠面板 (`st.expander`)，在生成回答的下方实时展示参考的原始条文，做到“有法可依”，极大增强了专业问答的可信度。
*   🔍 **轻量级高效检索 (Lightweight Retrieval)**：摒弃沉重的向量数据库 (Vector DB)，采用基于关键词/字面重合度的高效基础检索算法，降低部署成本，提升响应速度。
*   💻 **极简交互 (Streamlit UI)**：纯 Python 实现全栈，一键启动，无缝对接 DeepSeek 高性价比大模型。

## ⚙️ 技术架构与流程
本项目采用经典的单机 RAG（检索增强生成）架构，数据流转过程如下：
1. **文档解析**：读取本地 `data/规范.txt` 工程文档。
2. **条款切分**：通过正则表达式按“第X条”进行语义切片。
3. **相似度检索**：根据用户提问，匹配最相关的 Top-K 条文。
4. **Prompt 组装**：将检索到的条文与用户问题拼接成专属 Prompt。
5. **模型生成**：调用 DeepSeek API 生成回答，并强制要求附带引用来源。
6. **前端展示**：Streamlit 渲染结果，并提供原文折叠展示功能。
